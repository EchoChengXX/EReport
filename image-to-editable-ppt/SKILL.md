# 图片转可编辑 PPT

将用户图片重建为可继续修改的 PPTX。优先保持原图内容、顺序、布局、画布比例、配色、层级和连线关系，不重新策划或改写内容。本技能固化用户的图片复刻规范；用户当前指示可覆盖默认要求。

## 交付要求

- 交付原生 PPTX，不以 HTML 或整页图片替代。保留原始图片；多图默认一图一页，不自动加封面。
- 标题、正文、图例、标签和序号使用可编辑文字。文本转录以原图为准，不补写难以辨认的内容，不用近义词悄悄改写。放大核对仍不清晰时说明具体位置及疑点。
- 中英文统一为“微软雅黑”。对文本 run、段落默认格式及主题 major/minor 的 Latin、East Asian、Complex Script 字体槽显式设定。仅声明一个不生效的 API fontFamily 字段不算完成，必须检查实际 OOXML。不要下载或分发字体文件；渲染环境缺字体时说明预览限制。
- 卡片、框、线、箭头、关系图、基本几何图形重建为 PPT 原生形状或自由路径，可改尺寸、线宽、颜色和节点。按原图从底层到前景组织。
- **所有 icon 禁止使用位图裁片。** 可按原图重绘为原生矢量形状，或从公开矢量图库选择含义、线条风格相近且许可允许的素材，再转为 PPT 原生路径。保存素材出处及许可到备注或交付说明。嵌入 SVG 虽可无损缩放，但不自动等同于 PPT 内可编辑路径；要验证其编辑能力，优先原生路径。标志需保持准确，无法忠实重建时说明，避免误替换。照片等本来就是栅格内容可保留图片，不因图标规范矢量化照片。
- **文字与底框属于同一对象时合并。** 如 01、02、03、3.1 等序号、徽章或带字框，文字直接放到底框形状的 text body 中。避免同位置同尺寸的独立文本框盖在底框上。用户应一次选中即可移动整个带字形状，并直接改字。不要把整张图分组作为替代。
- **列表使用 PowerPoint 原生项目符号。** 正文中不输入前导“•/·”字符，不创建独立圆点对象。每条是一个原生段落，使用段落级 bullet、左缩进及悬挂缩进，续行对齐正文起点。
- **同组多个 bullet 必须在同一个文本框中。** 一条一个段落，统一段间距、固定/适当行距；不能一条一个文本框。同一卡片内的列表通常是一组，跨卡片或跨列的独立列表不合并。有背景且适合直接承载列表时，可放在该背景形状 text body 中。

## 实施流程

1. 检查源图尺寸、文字、视觉分区、图层和图标。整理对象清单与文字转录，先确定哪些内容组成一个文本框或带字形状。不要把本次示例中的内容或坐标固化为通用模板。
2. 使用当前可用的 presentations 技能及其本地工具完成 PPTX 创建、渲染和导出，先读取该技能。按图重建，不用其通用设计默认值改变原图。该技能对用户明确要求的可编辑图示允许原生形状。
3. 在创建时实现上述字体、合并和列表规则，优先避免导出后依赖坐标猜测自动合并。需要修补 OOXML 时只改相关属性，保留段落、层级、文字内容及背景样式，写入新文件。
4. 本地重建不依赖 cell_su7、cell_no_ai 或付费识别服务，不自动安装这些技能。若复杂图确实需要外部收费或上传服务，先说明实际需求、成本与待提交内容，再按用户授权处理；不要声称本技能能保证任意复杂图片完全还原。

## 验证与修复

- 按 presentations 技能完成最终导出验证。最后一次修改后重新渲染最终 PPTX，而不只检查早期草稿，逐页与原图对照。
- 检查漏字、错字、裁切、换行、文字溢出、遮挡、图层、连接线及画布比例。不要为消除校验警告而删除源内容。
- 运行 `python scripts/audit_pptx.py <最终文件.pptx>` 检查文件中的字体、原生 bullet、位图、可疑重复带字框和列表结构。可加 `--expect-no-images` 验证纯图示交付的零位图要求。脚本不替代视觉和语义核对。
- 确认每个列表组只有一个 text body、每条 bullet 为一个段落；序号文本位于背景形状内。对坐标相近的独立对象只报告疑点，不自动误合并。
- 抽查编辑性：中英文能修改，图标为原生路径，序号可单选带框移动，列表可在同一文本框中回车新增下一项。能检查 OOXML 但未实际打开 PowerPoint 时如实表述。
- 提供最终 PPTX，按需附预览。简要说明影响使用的还原差异，不宣称像素级一致或已在 PowerPoint 检查，除非确已验证。
