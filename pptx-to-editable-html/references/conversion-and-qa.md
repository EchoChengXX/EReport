# 转换机制与校验边界

## 为什么采用原稿语义与渲染图形双路径

- 从PPTX读取文本框、表格单元格、组合坐标和视频信息；从LibreOffice静态PDF读取可见文字与矢量路径。PDF只是中间格式，不是最终整页背景。
- PyMuPDF导出SVG时保留文本，不把所有字转成轮廓。浏览器计算对象边界，保存原变换、裁剪、渐变定义和图片。
- 按源文本框的内容与几何位置归属文字碎片，完整词组和段落成为一个对象，不按字符拆框。模糊归属保留碎片并在报告提示，不跨不同表格单元格盲合。
- 同一裁剪区域内的渐变色带先合成一体，再按原形状边界合并填色与轮廓。对于被渲染成蒙版暗色图片的阴影，只有图像特征和原形状几何均匹配时才附着到框体，避免整体移动后阴影留在原处。不要把渐变带分别作为可拖动对象。
- SVG引用的定义需要在当前页面及修改后的缩略图内可解析。导出保存更新数据源，而不是仅保存临时选中框或DOM。

坐标以各页真实SVG尺寸换算到1280×720，不依赖某份PPT的960×540渲染尺寸。隐藏页必须显式包含；页码映射使用 `sourcePage`，删视频后不再凭当前序号引用原稿。

## 需要专门复核的情况

1. **字体**：渲染端与浏览器字体不一致可导致宽度、字重和换行差异。确认本机可用字体；不要把替代字体下的截图称为逐像素一致。
2. **旋转与异形文本**：文字归属依赖源框和内容匹配；旋转、WordArt、已转轮廓文字或嵌入对象可能无法恢复语义。原稿若本身是图片页，应说明无法直接得到内部可编辑文字。
3. **连接线和层级**：LibreOffice可能把组合内肘形箭头渲染越界，或穿过正文。先核对原PPT连接起止点，再修复路线和前后层级；不能把某份原稿的页码、绿色或固定坐标写成通用删除规则。越界影子、出血图和有意裁剪不等于错误。
4. **表格**：按单元格归属文字，不能把整张表的文字合成一个框。跨行跨列、表内多段和计算表达式要逐项核对。
5. **渐变与复杂形状**：裁剪区域可能包含多层效果，合并后检查边界和叠放次序。合并“视觉上同一框”不等于合并所有同色图形。
6. **标题**：统一位置字号是可选编辑，不是复刻默认行为。内容页可用左48、上28、34px的WebReport字阶；长标题可以调整，Logo区留白。封面、章节页、暗页有不同角色，不强行同构。
7. **文字改写**：初始SVG保留原有多样式显示；重新输入段落后使用框主字号/字体/颜色。增字可能需要扩大框或调整排版。不得由“整体可编辑”推导“所有原PPT文字格式可无损往返”。

## 对失败的合理处理

源文件不改动；先在临时工作目录修复已定位的问题。只保留最终交付，临时检查报告不进入用户资料库。渲染失败或页数不一致就停止映射；不要静默遗漏页面。某些对象无法准确重建时，说明具体页面和对象类型，保留视觉资源并让用户知道限制。

CLI支持 `--work-dir` 留存 `final-deck.json` 以便定点修复。可以导入 `scripts/convert.py` 的 `render_html(deck, output)` 从调整后的数据重建HTML。修改后重新运行验证脚本及截图检查，不把一次样例通过泛化为任意PPT都完全兼容。

## 行为验收

- 正确页数与源页映射，视频按用户范围处理。
- 原稿完整句子/段落可作为一个对象修改，保存重开仍存在。
- 渐变框整体移动和缩放，不留下孤立碎片。
- 多选、组合/解组、置顶/置底、撤销重做可用。
- 放映时不能编辑、删除或通过快捷键修改对象。
- 最终文件无外部脚本、远程字体或临时目录运行依赖。

`verify.cjs`自动覆盖逐页加载、多行文字、移动、缩放、撤销、导出重开与放映只读。多选、组合、复杂SVG填色及关键页视觉需要根据实际对象补充检查。先试代表页，再全稿检查。

## 声明式定点修复

需要修复连接线或层级时，先检查临时 `final-deck.json` 中的源页和对象ID，构造明确的修复JSON，通过 `--patches /tmp/repairs.json` 重建到另一个临时输出。不把针对某页的修复写成脚本通用规则。`source_sha256` 可绑定源文件，防止误用。

```json
{
  "source_sha256": "原文件的SHA256，可省略",
  "pages": [
    {
      "sourcePage": 7,
      "remove_ids": ["s7_e12"],
      "update_by_id": {"s7_e18": {"x": 84, "y": 150}},
      "add_elements": [
        {"id": "repair-arrow", "type": "vector", "kind": "shape", "text": null,
         "x": 300, "y": 200, "w": 80, "h": 20,
         "svg": "<svg xmlns=\"http://www.w3.org/2000/svg\" viewBox=\"0 0 80 20\" width=\"100%\" height=\"100%\"><path d=\"M0 10H75M68 3L75 10L68 17\" fill=\"none\" stroke=\"#3387f6\" stroke-width=\"2\"/></svg>"}
      ]
    }
  ]
}
```

调整只作用于已选择的原页；不认识的对象ID或不匹配的指纹会报错，不能静默修复到另一份材料。顺序改变也可在临时数据中完成，再通过 `render_html` 生成文件。修复报告保留原始风险提示，表示还需要目视复核，并不因打过补丁就认定问题已解决。
